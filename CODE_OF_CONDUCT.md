# Community code of conduct

This code applies to issues, discussions, reviews and other project spaces. Help contributors reproduce results, explain disagreements with evidence, and respect people with different levels of experience. Use synthetic examples when sharing logs or decisions.

Harassment, threats, discriminatory remarks, personal attacks, and disclosure of another person's private information are grounds for moderation. Maintainers may edit or remove material, lock a thread, or restrict participation according to severity and recurrence.

For a public thread, use GitHub's **Report content** menu and choose the repository admins when available. You can also report abuse privately to [GitHub Support](https://support.github.com/contact/report-abuse). For a vulnerability in the runtime, use the [security reporting channel](SECURITY.md).
